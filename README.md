# Python Fundamentals: Data Structures & Conditional Logic

This project demonstrates the use of core Python concepts, including Lists, Dictionaries, Sets, and Conditional Statements. It covers common operations such as data manipulation, searching, sorting, set operations, and decision-making using conditional logic. The project is designed to strengthen foundational Python programming skills through practical examples and hands-on problem solving.

Key Concepts:

List creation and manipulation
Dictionary operations and data access
Set operations (union, intersection, uniqueness)
User input handling
Conditional statements (if, elif, else)
Basic data analysis and categorization
